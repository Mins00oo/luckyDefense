# 2차 설계 및 구현 계획

기존 전장/경로/공격/유닛 데이터/확률을 유지하고 Session, Board, Tower, HUD를 확장한다.

- PREPARATION(10초), COMBAT, PAUSED(이전 단계 보존), GAME_OVER.
- 최초 실행 및 재시작 즉시 PREPARATION. 초기 100G, 소환 50G, 판매 25G.
- 준비 중 적/전투/웨이브 타이머 정지. 준비 종료 시 무조건 1웨이브.
- Session이 선택 유닛과 pending_sale 참조를 소유. Board는 슬롯/외부 클릭만 전달.
- 미선택 상태에서 빈 칸은 소환 위치 선택. 유닛 선택 후 슬롯 클릭은 이동/교환.
- 선택 해제는 ESC, 전장 빈 배경 클릭, HUD 선택 해제 버튼(터치 지원).
- 이동 시 slot/position/occupied를 원자적으로 갱신. 공격 쿨다운 보존, 다음 탐색은 새 좌표.
- 판매는 요청 → 다른 위치의 확인 버튼. 모델에서도 선택·소유·활성 상태 재확인.
- 선택 변경/이동/일시정지/재시작/패배는 판매 확인 무효화. 삭제 전에 배열/격자/선택에서 제거.
- 기존 우측 패널을 선택 시 상세정보/판매 패널로 전환. 비선택 시 기존 확률 카드.
- 별도 유닛 외곽선과 Board 사거리 표시. 임시 visual_scene 교체 구조 유지.

## 구현/검증 순서
1. 준비/일시정지/무소환 시작/재시작, 이동/교환/이후 자동공격, 판매/중복 환불/재소환 테스트.
2. Session 상태 및 트랜잭션, Board 입력, Tower 선택 표시 추가.
3. 기존 HUD에 카운트다운, 상세정보, 판매 확인 통합.
4. 기존 테스트를 새 경제/상태 규칙으로 갱신하고 전체 회귀 검사.
5. Windows 렌더러에서 실시간 10초 준비 → 첫 웨이브, 입력 시나리오 및 화면 캡처 검증.

판매/소환 반복의 순손실은 25G이며 외부 처치 보상 외에는 자금이 증가하지 않아야 한다.
이번 범위에서 유닛 종류/능력치/확률/웨이브 수식은 변경하지 않는다.
