# 4차 설계 및 구현 계획

기존 Session/Combat/Enemy/Board/HUD와 재사용 가능한 visual_scene 구조 유지.
유형7종과 등급5단계를 독립 Resource로 추첨. 유형 가중치는 카탈로그 내 각 유형,
등급 정수 가중치는6000/2600/1000/350/50으로10000등분하여0.5%를 정확하게 정의한다.
두 번의 독립 추첨을 동일한 시드 RNG로 재현한다. 기존3차 결과는 docs/baseline에 보존.

## 유형
- ASSAULT: 작은 보병, 단일 연사.
- MARKSMAN: 보병/긴 소총, 장거리/방어력 관통/중장갑 우선.
- SIEGE: 대형 궤도 차량, 범위 포격. 기존형 계승.
- VULCAN: 작은 기계/다중 포신, 초고속 저피해 연사.
- LANCER: 중형 에너지 기계, 직선 관통. 기존형 계승.
- INCINERATOR: 화염장비 보병, 짧은 원뿔 범위/시간 기반 연소.
- DISRUPTOR: 공중 전자전 드론, 저피해/일시 감속.

## 상태/등급
Tower는 원본 유형과 등급을 참조하고 유효 능력치를 계산한다. 원본 리소스를 변경하지 않는다.
등급별 공격력/공격주기/사거리/방어 관통/특수효율을 데이터에서 정의한다.
범위·광선폭·화염 대상수/연소·감속효율은 각 능력의 상한을 지킨다.
연소는 유닛별 재적용 시 갱신, 최대3개 출처만 동시 적용. armor에 따른 비율 감쇄, 프레임당 최소1 피해 금지.
감속은 출처별 지속시간을 관리하고 가장 강한 값만 적용, 최대50%, 지속시간 최대3초.
판매한 유닛의 이미 부여된 상태효과는 짧은 만료까지 유지하고 노드 참조를 보관하지 않는다.
소환 연출/희귀알림은 비차단 시각효과이며 전투/시간을 멈추지 않는다.

## 검증
1. 테스트 먼저: 7×5 조합 생성, 독립 리소스, 모든 유형 이동/교환/판매.
2. 실제 공격 로직의 단일/방어관통/광역/관통/원뿔/연소/감속, 상한/만료/정지 검증.
3. 100만 고정시드 추첨, 등급 경계 전수10000구간 검사, 유형×등급 분포.
4. 동일 전략/시드1..100의3차 저장 통계와4차 비교. 강/약 초기 조합과 전설1기 무성장 대조군.
5. 기존 회귀 테스트 및 Windows 실제 렌더링,7종 실루엣과 등급/알림/정보 패널 확인.

초기100G/소환50G/판매25G/준비10초/60적 패배 유지. 보스/강화/합성/유물/인벤토리/BGM/iOS 미포함.
