# 3차 분석 및 구현 계획

## 변경 전 코드 분석
- Enemy.advance: fposmod로 거리 순환. 한 바퀴마다 제거되지 않음.
- _next_wave는 enemies를 비우지 않음. 생존 적은 다음 웨이브에도 유지.
- 상단 enemies.size()/60 = 현재 생존 적/패배 한도. spawn_enemy에서 60기 즉시 패배.
- 기존 HP = 34 × 1.19^(wave-1), 속도 = min(72+2×wave, 140), 방어력 없음.
- HP: W1 34, W3 48.15, W5 68.19, W13 약274.18.
- 보상 = 10 + floor((wave-1)/3), 처치 signal에서 1회 지급. 기존 별도 웨이브 보상 없음.
- 18초마다 min(10+2×wave,25)마리, 0.65초 간격으로 출현.
- 명목 단일 대상 DPS: 벌컨 9/0.22=40.91, 시즈 42/1.35=31.11, 랜서 34/0.85=40.00.
  실제 시간당 피해는 physics tick 양자화, 사거리, 오버킬, 다중 적중에 따라 다름. 실측 테스트 추가.

## 설계
유닛 종류·등급·능력치·55/30/15 소환 확률은 유지한다.
초기 100G, 소환50G, 준비10초, 판매25G 유지.
EnemyDefinition Resource와 visual_scene을 분리하여 일반/속공/중장갑/군집 추가.
WaveDirector Resource에 초반 편성·출현간격·HP 성장·속도 성장·웨이브 보급 저장.
방어력은 타격당 고정 차감(최소 피해1). 여러 타격을 주는 벌컨과 고피해/다중 적중 포탑 간 역할 분화.
처치 보상은 타입별 소액 고정, 웨이브 보급은 생존하여 다음 웨이브에 진입할 때 1회만 지급.
누적30/45/54기 경고, 생존 적 막대와 타입 범례. 화면 전체 디자인 유지.
최대60기의 적, 24포탑, 이펙트 상한을 유지. 체력바는 피격 시에만 다시 그리기.

## 검증/보정
1. 누적/웨이브 보상 중복 방지/방어력/선택토글/우클릭 테스트를 먼저 작성.
2. 실제 Session/Enemy/Combat 코드로 60Hz 시뮬레이션. 별도 수학적 대체 모델 금지.
3. 기본 정책: 50G마다 즉시 소환, 고정 배치 순서, 판매/이동 없음. 시드1..100 이상.
4. 같은 후속 소환 시드에서 초기 벌컨2 vs 시즈+랜서 비교, 초기 두 유닛만 유지하는 성장 실패 실험도 별도로 수행.
5. 4웨이브 이내 패배, 10웨이브 도달, 웨이브 종료/패배 시점의 잔여 골드·생존 적 평균과 표본수, 실제 패배, 조합별 차이 출력.
6. 실측 결과에 따라 적 데이터만 보정하고 최종 데이터로 전체 시뮬레이션 재실행.
7. Windows 실제 렌더링/기존 기능 회귀 검증. 모든 결과는 자동 정책 조건부 통계이며 사람 승률로 간주하지 않는다.
