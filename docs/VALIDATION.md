# 검증 기록 — 2026-11-20

환경: Windows, 공식 Godot 4.4.1 stable 포터블, Compatibility / Intel Iris Xe OpenGL 3.3.

- `test_loop.gd`: 상태 전환, 시작 자금, 비용, 중복 슬롯/자금 부족/전체 슬롯 포화 시 무차감, 사망 보상 1회, 순환 경로, 일시정지 중 이동 정지, 3종 공격과 비대상 보호, 웨이브, 적 60기 패배, 재시작 통과.
- 고정 시드 10,000회 소환에서 55/30/15% 분포 오차 2.5%p 이하 확인. 빈 카탈로그 안전 처리 확인.
- `test_input.gd`: 실제 Viewport 입력 이벤트로 시작 → 슬롯 17 클릭 → 소환 → Space 일시정지 → 계속 → 재시작 통과.
- `test_simulation.gd`: 고정 시드 90초 자동 플레이, 5웨이브 / 80처치 / 16포탑 / 잔여 적 0.
- `capture_preview.gd`: Windows GPU로 씬 렌더링 및 PNG 저장 성공. `preview.png`에서 한국어 글꼴, HUD, 체력바, 포탑/적, 경로 및 레이아웃 확인. 이 프리뷰는 시각 확인용으로 유닛과 적을 추가한 테스트 장면이다.
- 코드 리뷰 이후 버튼의 키보드 포커스를 비활성화해 클릭했던 버튼이 전역 단축키를 가로채지 않도록 예방.
- 입력 테스트 중 포인터 전역 상태에 의존하던 슬롯 선택을 이벤트 좌표 기반으로 수정하고 재검증.
- UI 검증에서 진행 막대의 최소 높이가 상태 문구를 가리던 현상 수정 후 재캡처 확인.

검증 범위 밖: Windows 독립 실행 파일 export, iOS export/서명/실기기, 장시간 발열, 최종 게임 밸런스.
현재 `.tools` 포터블 엔진 또는 Godot 편집기로 Windows에서 플레이 가능.
