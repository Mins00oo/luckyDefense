# Iron Perimeter — 1차 구현 설계 및 계획

## 범위
Godot 4 / GDScript, 외부 플러그인 없음. Windows 우선, iOS 가로 화면 고려.
중앙 6×4 슬롯, 외곽 폐곡선, 자동 전투, 가중치 소환, 무한 웨이브.
임시 그래픽은 자체 벡터 드로잉이며 교체 가능한 별도 visual scene이다.

## 구현 결정
- 1280×720 논리 화면, canvas_items / keep로 비율 유지 및 레터박스.
- 시작 자금 180, 소환 60, 적 누적 60기 패배. 빈 칸 선택 또는 자동 배치.
- 연사 / 범위 포격 / 직선 관통 = 가중치 55 / 30 / 15.
- 18초 주기 웨이브, 체력·수·속도 증가. 전멸 대기 없이 누적되어 디펜스 압박.
- 데이터 Resource, 경로/격자 Board, 공격 Combat, 상태 GameSession, HUD 분리.
- Path2D/PathFollow2D 대신 폐곡선 Curve2D 샘플링: 이동 거리와 전투 좌표를 단순화.
- 화면 조작은 마우스와 에뮬레이트된 터치 클릭, 키보드는 보조 기능.

## 순서 및 검증
1. 통합 테스트 작성: 시작/소환 비용/중복배치/보상/경로 순환/3종 공격/일시정지/패배/재시작.
2. 데이터, Board, Enemy, Tower, Combat과 GameSession 구현.
3. 메탈 전장, 교체 가능한 유닛 visual, HUD 및 씬 조립.
4. Godot headless import와 통합 테스트 실행. 가능하면 렌더링도 확인.
5. 실행 안내 및 확장 포인트 문서화.

## 제외 및 향후 검증
합성, 강화, 저장, 상점, 광고, 사운드, 최종 아트, 실제 iOS 빌드는 이번 범위 밖.
iOS 안전영역·기기 발열·실기기 터치 및 GPU 프로파일링은 Mac/iPhone 단계에서 확인.
